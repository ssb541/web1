# 🏢 단지 타이쿤 — 관리소장 이야기 (1차 MVP)

롤러코스터 타이쿤 감성의 **한국 아파트 단지 관리·운영 타이쿤** 웹 게임.
HTML5 Canvas(쿼터뷰 픽셀 렌더링) + TypeScript + Vite, 외부 에셋 없음(모든 그래픽을 코드로 그림).

## 실행 방법
```bash
cd apt-tycoon
npm install
npm run dev        # http://localhost:5173  (모바일은 같은 와이파이에서 Network 주소로 접속)
npm run build      # 정적 빌드 → dist/ (아무 정적 호스팅에 올리면 실행됨)
```

## 조작법
| 동작 | PC | 모바일 |
|---|---|---|
| 화면 이동 | 빈 곳 드래그, WASD/방향키 | 한 손가락 드래그 |
| 확대/축소 | 휠, `+` `-` | 두 손가락 핀치, ➕➖ 버튼 |
| 건설 | 하단 메뉴 선택 → 지도 클릭 (`R` 회전, 우클릭/Esc 취소) | 메뉴 탭 → 지도 탭 |
| 건물 업그레이드/철거 | 건물 클릭 → 좌측 패널 | 동일 |
| 입주민 만족도/불만 | 입주민 클릭 | 탭 |
| **직원 배치** | 직원을 **드래그해서 집어 올려** 원하는 곳에 놓기 (반경 6칸이 담당 구역, 민원 마커 위에 놓으면 즉시 투입) | 길게 끌어서 놓기, 또는 직원 선택 → "📍 지도에서 위치 지정" |
| 시간 | Space 일시정지, 1/2/3 배속 | 상단 ⏸ ▶ ▶▶ ▶▶▶ |

## 게임 규칙 요약
- **시설**: 아파트 동 / 주차장 / 놀이터 / 분리수거장 / 경비실 / 화단 / 조경수 (관리사무소는 기본 제공). 아파트·주차장·놀이터·분리수거장·관리사무소는 업그레이드 가능.
- **직원 4종**: 관리주임(소음 중재·순회 상담) / 기전기사(승강기·동파·방역·정비) / 경비원(이중주차·순찰) / 미화원(쓰레기·예초·제설·낙엽). 월급이 나가며, 직원 정원은 관리사무소 레벨에 따라 6→10명.
- **돌발 민원**: 승강기 고장, 이중주차 갈등, 층간소음, 분리수거장 넘침, 여름 예초, 봄·여름 방역, 가을 낙엽, 겨울 동파·빙판길 제설. 제한 시간 내 담당 직원이 처리하거나 비용을 내고 **외주**로 즉시 해결. 기한을 넘기면 민원 게이지 상승.
- **경영 지표**: 보유 자금, 월 관리비 수입/지출(매월 말 정산), 만족도, 민원 게이지, 날짜·계절, 단지 등급(★1~5).
- **패배(해임)**: 민원 게이지 100% / 만족도 20% 미만 15일 지속 / 자금 -2,000만원 이하.
- **승리**: 단지 등급과 만족도를 유지해 `관리주임 → 관리과장 → 관리소장 → 단지 총괄소장 → 명품 5성 단지 소장`으로 승진.
  현황 탭(📊)에서 다음 등급 조건 체크리스트를 확인하세요.

## 코드 구조
- `src/data.ts` 상수/시설·직원 정의
- `src/game.ts` 시뮬레이션(길찾기, 입주민·직원 AI, 민원 이벤트, 경제, 등급)
- `src/render.ts` 쿼터뷰 도트 렌더러(지면 타일, 건물, 인물, 말풍선 오버레이)
- `src/main.ts` 입력/HUD/패널 UI
